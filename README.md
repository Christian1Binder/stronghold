# Stronghold – Burgwirtschaft

Ein Stronghold-inspiriertes Browser-Aufbauspiel mit Phaser und Vite. Die aktuelle Version umfasst Gebäudebau, laufende Rohstoffproduktion, Arbeitskräfte, Bevölkerung, Nahrung, Beliebtheit, Rationen, Steuern sowie einen dynamischen Markt mit automatischen Kauf- und Verkaufsregeln.

## Lokal starten

```bash
npm ci
npm run dev
```

Tests und Produktions-Build:

```bash
npm test
npm run build
```

Der Spielstand wird automatisch im Browser gespeichert. Änderungen auf `main` werden nach erfolgreichen Tests automatisch auf GitHub Pages veröffentlicht.
